# Week 12 In-Class Lab: Start Your Final Project

**Course:** CST 2412 Data Security, Privacy, and Ethics  
**Work mode:** Individual only  
**Due:** End of class  
**What you submit:** This completed lab as one document  
**Purpose:** Leave class with a realistic final project idea, not just a vague topic.

## What This Lab Helps You Do
By the end of class, you should have:
- chosen the coding project path or research essay path
- written one focused project question
- connected your idea to course concepts
- identified the data or sources you need
- written a short starting plan

This is not the final project.
This is the project-start worksheet that helps you make the final project manageable.
