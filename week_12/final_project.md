# Final Project Assignment

**Course:** CST 2412 Data Security, Privacy, and Ethics  
**Project type:** Individual  
**Syllabus requirement:** Final project report and in-class presentation  
**Goal:** Apply course concepts to one focused security, privacy, or ethics question.

## The Simple Version
Choose **one** path:

1. Beginner coding project
2. Brief research essay

Both paths can earn full credit.
The coding path is not automatically better.
The research essay path is not automatically easier.

Your project should be small, specific, and complete.

## What Makes a Good Topic?
Your final project should answer one clear question.

Good questions:
- How can login metrics help a security analyst identify suspicious access?
- What privacy risks come from student monitoring software?
- How should a cloud database storing sensitive records be protected?
- What can go wrong when different datasets are linked together?
- How can a small organization use logs without turning monitoring into surveillance?

Weak questions:
- Is cybersecurity important?
- Is AI good or bad?
- Is privacy dead?
- What is hacking?

## Option A: Beginner Coding Project

Create a small security or privacy analysis using code.

Recommended tools:
- Python with pandas
- DuckDB or SQLite
- Jupyter or Colab
- a simple dashboard or web app only if you already know how to build one

You may use:
- the Week 11 CSV files
- the Week 12 CSV file
- a small fictional dataset you create yourself
- a safe public dataset

Do **not** use real private data from classmates, family, work, or school systems.

### Beginner Coding Ideas
Choose one or propose your own:

1. Login anomaly notebook
   Analyze failed logins, successful logins after failures, MFA denials, and suspicious systems.

2. Alert triage scorecard
   Rank alerts by severity, confidence, asset criticality, exposure, and sensitive data.

3. Privacy-aware data inventory
   Build a table of systems, data types, users, retention periods, and privacy risks.

4. Cloud database security checklist
   Score fictional cloud databases based on access control, encryption, backup, logging, and public exposure.

5. Monitoring boundary analysis
   Compare useful security signals with privacy risks and recommend what should be logged, limited, or deleted.

### Coding Project Deliverables
Submit:
- your notebook, script, or small app files
- a short written report of **700-1000 words**
- a short presentation

Your report must include:
- project question
- dataset description
- what your code does
- two or three findings
- one security recommendation
- one privacy or ethics concern
- one limitation

### Minimum Coding Requirements
Your code should do at least **three** of these:
- load a CSV file
- filter rows
- group or count values
- sort by risk or priority
- create a simple score
- make one chart
- join two small tables
- produce a short summary table

Keep it small.
A clean notebook with clear comments is better than a complicated project that barely runs.

## Option B: Brief Research Essay

Write a short research essay about one security, privacy, or ethics issue connected to the course.

Your essay should be **1000-1300 words**.
It should use at least **three credible sources**.
At least one source should be from a government, standards organization, academic publisher, official documentation page, or reputable investigative/reporting source.

### Beginner Research Ideas
Choose one or propose your own:

1. Student monitoring software
   What security problem does it claim to solve, and what privacy or ethics risks does it create?

2. Data brokers and personal data
   How do linked datasets create privacy risk, even when each dataset seems harmless by itself?

3. Facial recognition in public or school settings
   What are the security arguments, privacy concerns, and fairness concerns?

4. Cloud database exposure
   Why do cloud databases get exposed, and what basic controls reduce the risk?

5. Security logging and surveillance
   When does logging help protect systems, and when does it become excessive monitoring?

6. AI hiring or recommendation systems
   How can automated classification reproduce bias, and what accountability controls should exist?

7. Forensic Architecture and evidence
   How can technical reconstruction support human rights investigations, and what limits should investigators acknowledge?

### Research Essay Deliverables
Submit:
- a short research essay
- a short presentation

Your essay must include:
- clear research question
- background on the technology or case
- one security issue
- one privacy or ethics issue
- one connection to the course
- one recommendation
- source list

## Presentation Requirement
Everyone gives a short presentation.

Your presentation should answer:
1. What topic did you choose?
2. What question did you investigate?
3. What evidence did you use?
4. What did you find?
5. Why does it matter for security, privacy, or ethics?
6. What should someone do differently because of your project?

## What Not To Do
Do not:
- attack real systems
- scan websites without permission
- collect private data from real people
- submit AI-generated writing without revising and understanding it
- submit a broad summary with no argument
- build malware, phishing pages, credential collectors, or anything designed to harm systems

## Grading Focus

| Category | What I am looking for |
|---|---|
| Focused question | One clear, specific question |
| Course connection | Accurate use of course concepts |
| Evidence | Data, sources, or concrete examples that support the argument |
| Security analysis | A real security issue, risk, control, or tradeoff |
| Privacy and ethics | A clear privacy or ethics concern |
| Recommendation | A realistic recommendation connected to the evidence |

## Reminder
Small, specific, and complete is better than big, vague, and unfinished.
