# Week 12: Security Analytics and Dataset Documentation

## Week focus
Week 12 continues the syllabus unit on **Data Analytics for Security**.

The week has two student-facing parts:
- a guided security metrics lab using a small CSV
- a transition into dataset documentation work for the final project

Final project materials are consolidated in one root-level packet:
[final_project/README.md](/Users/atiliobarreda/Desktop/academics/teaching/courses/CST2412_Data_Security_Privacy_Ethics/final_project/README.md).

The final project is an individual project where students choose either a beginner security analyst coding project or a brief MLA research essay about a course-related security, privacy, or ethics issue.

The completed final project is due **May 22, 2026**.

## Syllabus alignment
From `CST_2412.pdf`:
- Week 11-12 topic: Data Analytics for Security
- Week 13 topic: Data Poisoning and Model Evasion
- Week 14-15: Final project work and final submission

## Textbook alignment
The required textbook is Pfleeger, Pfleeger, and Margulies, *Security in Computing*.

Useful textbook connections for this week:
- audit logs as evidence of access and activity
- intrusion detection as a way to identify suspicious behavior
- database and data mining security
- privacy risk when separate data sources are linked
- privacy-preserving data mining as a reminder that useful analysis should still respect people

## Work mode
All Week 12 activities are **individual**.

## Recommended class flow

### Day 1: Security Metrics
1. Mini lesson: security analytics, metrics, and privacy-aware monitoring
2. Guided analytics lab: students inspect a small security metrics table
3. Short analyst note: students explain one priority choice and one privacy boundary

### Day 2: Dataset Documentation
Use the consolidated packet:
[final_project/README.md](/Users/atiliobarreda/Desktop/academics/teaching/courses/CST2412_Data_Security_Privacy_Ethics/final_project/README.md).

Suggested flow:
1. Mini lesson: dataset sources, data dictionaries, and why dataset structure matters
2. Individual dataset lab: students choose a dataset source, create a mini data dictionary, and document concerns
3. End-of-class submission: students submit the dataset lab
4. Homework: video response on open data, data dictionaries, and responsible analysis
