# Week 12: Security Analytics and Final Project Launch

## Week focus
Week 12 continues the syllabus unit on **Data Analytics for Security** and then transitions students into the individual final project.

The class is designed to be practical and not too hard:
- first half: a guided security analytics lesson and short lab
- second half: final project explanation and an in-class lab due at the end of class

## Syllabus alignment
From `CST_2412.pdf`:
- Week 11-12 topic: Data Analytics for Security
- Week 13 topic: Data Poisoning and Model Evasion
- Week 14 topic: Final Project Presentations
- Week 15 topic: Final Project Due and Wrap-Up

The Week 12 goal is to finish the analytics unit while giving students enough structure to begin the final project before presentations.

## Textbook alignment
The required textbook is Pfleeger, Pfleeger, and Margulies, *Security in Computing*.

Useful textbook connections for this week:
- audit logs as evidence of access and activity
- intrusion detection as a way to identify suspicious behavior
- database and data mining security
- privacy risk when separate data sources are linked
- privacy-preserving data mining as a reminder that useful analysis should still respect people

## Work mode
All Week 12 work is **individual**.
Students may ask questions, but the labs, project choice, and final project are individual work.

## Recommended class flow

### Day 1: Finish Security Analytics and Launch the Final Project
1. Mini lecture deck (25-30 min): security analytics, metrics, privacy-aware monitoring, and final project choices
2. Guided analytics lab (25-30 min): students inspect a small security metrics table and write a short analyst note
3. Final project launch lab (25-30 min): explain the two project options and have students begin the in-class final project lab

### Day 2: Individual Final Project Studio
1. Short framing (10 min): review the two project paths and what a good beginner project looks like
2. Individual final project lab time (55-65 min): students choose a path, draft a project question, find sources or data, and complete the lab
3. End-of-class submission (5-10 min): students submit the completed in-class lab

## Instructor note
The easiest path through this week is:
1. use the deck to frame why security analytics is career-relevant
2. have students complete the short metrics lab
3. explain the final project options clearly
4. give students real class time to complete the final project in-class lab

The final project should feel manageable: students are not being asked to become experts, run attacks, or build a large application. They are being asked to make a clear security, privacy, or ethics argument using course concepts and evidence.
