# Week 12 Day 1: Security Metrics

## Focus
Day 1 uses one required class dataset, **Campus Systems Daily Security Metrics**, to help students practice prioritizing systems for review.

Students do **not** need to choose a dataset for this day.

## Files
- `week12_security_analytics_final_project_launch.pptx`
  Student-facing PowerPoint for Day 1.

- `week12_security_analytics_final_project_launch.pdf`
  PDF version of the Day 1 slides.

- `lab_day1_security_metrics.md`
  Individual lab using the security metrics CSV.

- `data/week12_security_metrics.csv`
  Required fictional security metrics dataset for the lab.

## Class flow
1. Mini lesson: security analytics, metrics, and privacy-aware monitoring
2. Guided lab: students inspect and score all ten systems in the security metrics table
3. Short analyst note: students explain one priority choice and one privacy boundary

## Final project connection
This day supports students who may choose the beginner security analyst coding project path.
