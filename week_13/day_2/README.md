Day 2 uses model evasion as a practical way to help students write better limitations and recommendations for the final project.

## Class flow
1. Mini lesson: evasion, false positives, false negatives, thresholds, and overclaiming
2. Short Colab walkthrough: thresholds can miss or over-flag risky systems
3. Individual lab: students write a mini threat model, limitation section, and recommendation for their final project
4. Exit writing: students name one realistic recommendation and one limitation

## Timing
This can fill a 1:40 class period.

Suggested pacing:
- 25-35 minutes: PowerPoint mini lesson
- 10-15 minutes: Colab notebook walkthrough
- 45-50 minutes: individual lab
- 10-15 minutes: exit ticket and submission

If class runs longer, use extra time for students to revise their final project question, limitation, or recommendation.

## Final project connection
Students leave with a draft threat model, limitation paragraph, and realistic recommendation they can reuse in the final project.
