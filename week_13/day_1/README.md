# Week 13 Day 1: Data Poisoning and Dataset Trust

## Focus
Day 1 uses data poisoning as a practical way to help students question final project evidence.

## Class flow
1. Mini lesson: data poisoning, bad labels, bad sources, missing data, and feedback loops
2. Short Colab walkthrough: changed data can change a security priority ranking
3. Individual lab: students complete a final-project dataset/source trust check
4. Exit writing: students explain what could make their evidence misleading

## Final project connection
Students leave with a clearer evidence plan and one limitation they can use in the final project.
