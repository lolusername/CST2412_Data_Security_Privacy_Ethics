# Week 15: Last Class Review, Portfolio, and Interview Language

## Class focus
Today is the final class meeting: **May 19, 2026**.

The goal is to review what students learned in CST 2412 and turn that learning into something useful after the course:

- a clear vocabulary for security, privacy, and ethics
- a small GitHub portfolio artifact explaining one course concept
- job-interview language for talking about class projects and skills
- final project reminders before the due date

The final project is due **May 26, 2026**.

Students are **not giving a presentation**.
