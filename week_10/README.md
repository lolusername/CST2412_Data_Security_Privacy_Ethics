# Week 10: Privacy, Law, and Ethics Through Chun and Benjamin

## Week focus
This class uses Ruha Benjamin and Wendy Hui Kyong Chun to help students analyze claims about technology, data, and social power.
Core thread for the week:
- identify one key claim from each speaker
- compare how each speaker explains technological harm
- apply those ideas to one concrete system or platform
- turn discussion into a short evidence-based in-class argument
