# Week 9 Short Writing Follow-Up

## Time
8-10 minutes

## Length
120-150 words

## Prompt
After translating one workspace from tables into a JSON-style document, answer this question:

**Why might a cloud app prefer the JSON/document version for some tasks, even if the original table version is still useful?**

## What your answer must include
1. one reason the document version helps
2. one reason the table version is still useful
3. one real use case

## Sentence starters
- `A cloud app might prefer the document version because ______.`
- `The table version is still useful because ______.`
- `This matters most when the app needs to ______.`

## Grading Criteria
- Clear explanation
- One benefit of document logic
- One benefit of table logic
- One realistic use case

## Common Mistakes to Avoid
- saying one model is always best
- giving only definitions
- forgetting to name a use case
