# Week 9: GitHub Education, MongoDB Atlas, and Guided Cloud Database Onboarding

## Week focus
This week uses the MongoDB Atlas and GitHub Education material from Week 8 in a slower, guided student activity format.
Core thread for the week:
- identify the MongoDB-related GitHub Education benefit
- explain basic Atlas vocabulary in plain language
- follow a simple safe setup plan
- connect cloud-database onboarding to basic security habits

## Recommended class flow
1. Quick recap (10-15 min): review the Week 8 deck highlights on Atlas and student benefits
2. Full-class individual lab (55-70 min): students complete the guided Atlas/GitHub Education lab
3. Short writing follow-up (8-10 min): students complete the simplified response if time allows
4. Debrief (5-10 min): clarify setup blockers, security mistakes, and next steps

## Week 9 files
- `week_09/lab.md`
  Easy guided full-class individual activity based on the official GitHub Education Pack and MongoDB Atlas onboarding flow.
- `week_09/in_class_reading_response.md`
  Short writing follow-up on relational versus document-model choice.

## Instructor note
Week 9 works best as a low-pressure practice week.
Students should be able to complete the lab using either:
1. live account access, or
2. documentation-only analysis.
