# Week 9: Translating Tables into JSON and Document Logic

## Week focus
This week slows down and turns the Week 8 database ideas into a guided student activity.
Core thread for the week:
- identify keys and relationships in the Week 8 CSV files
- trace how related rows connect across tables
- translate one workspace from table logic into JSON/document logic
- explain when a document shape is useful and what tradeoff it creates

## Recommended class flow
1. Quick recap (10-15 min): review the Week 8 guide sections on tables, JSON, and documents
2. Full-class individual lab (55-70 min): students complete the guided table-to-JSON/document translation lab
3. Short writing follow-up (8-10 min): students complete the simplified response if time allows
4. Debrief (5-10 min): compare student JSON documents and discuss when document logic helps

## Week 9 files
- `week_09/lab.md`
  Easy guided full-class individual activity on translating the Week 8 table data into JSON/document logic.
- `week_09/in_class_reading_response.md`
  Short writing follow-up on why an app might prefer document logic for some tasks.

## Instructor note
Week 9 works best as a low-pressure practice week.
Students should leave class able to:
1. read relationships across tables, and
2. turn those related rows into one clear JSON-style document.
