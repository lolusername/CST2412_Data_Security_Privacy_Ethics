# Week 8: Intro to Databases and Cloud Database Models

## Week focus
This week introduces table-based thinking before moving into cloud-hosted databases and MongoDB.
Core thread for the week:
- define tables, rows, columns, keys, and relationships
- compare a flat table, a relational table design, and a document-style design
- connect data-model decisions to cloud concerns such as duplication, access control, scale, and governance
- introduce MongoDB Atlas as a managed cloud database students can access with GitHub Student benefits

## Syllabus alignment
From `CST_2412.pdf`:
- Topic: Databases, Cloud, Big Data Security
- Reading: Chapters 7 and 8

## Recommended class flow
1. Table and JSON framing (15-20 min): use the main Week 8 deck and the PDF guide
2. GitHub Education + Atlas orientation (10-15 min): use the second deck to explain the Student Developer Pack and Atlas basics
3. Guided walkthrough (15-20 min): open the official GitHub Education Pack and Atlas setup URL together and preview the setup flow
4. Transition to Week 9 (5-10 min): explain that the hands-on lab and short writing follow-up will happen next week
