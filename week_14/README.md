# Week 14: Final Project Studio

## Week focus
Week 14 is a low-prep final project studio week.

Students use class time to turn their topic, evidence, data, sources, code, and limitations into a finished final project draft.

## Final project connection
The final project is due **May 26, 2026**.

Students are **not giving a presentation**. Week 14 replaces presentation prep with individual project development.

## Work mode
All Week 14 activities are **individual**.

## Recommended class flow

### Day 1: Turning Evidence Into Findings
1. Mini lesson: how to turn data, sources, and notebook outputs into findings
2. Sample project walkthrough: security metrics daily summary
3. Individual lab: students draft their project question, evidence list, findings, recommendation, and privacy/ethics paragraph
4. Checkpoint submission

### Day 2: Final Project Work Session
1. Short checklist lesson: what a complete final project needs
2. Individual work time: students continue the final project using the checklist
3. Exit ticket: students report what is complete, what remains, and what they will submit
