# Week 14 Sources and Research Anchors

Research checked on May 3, 2026.

## Course anchors
- `CST_2412.pdf`
  The syllabus lists Week 14 as final project work. This course version uses Week 14 as individual final project studio time rather than presentations.

- `final_project/README.md`
  The final project packet defines two paths: a beginner security analyst coding project or a brief MLA research essay.

- Pfleeger, C. P., Pfleeger, S. L., & Margulies, J. (2015). *Security in Computing* (5th ed.). Pearson.
  Useful project connections include authentication, access control, web security, network security, database security, cloud security, privacy, law, ethics, and security analytics.

## External anchors
- NIST, **AI Risk Management Framework**  
  https://www.nist.gov/itl/ai-risk-management-framework  
  Useful for framing recommendations as risk management rather than broad promises.

- NIST, **Adversarial Machine Learning: A Taxonomy and Terminology of Attacks and Mitigations**  
  https://www.nist.gov/publications/adversarial-machine-learning-taxonomy-and-terminology-attacks-and-mitigations  
  Useful for final projects that discuss data poisoning, evasion, limits, and model risk.

- OWASP, **Machine Learning Security Top Ten**  
  https://owasp.org/www-project-machine-learning-security-top-10/  
  Useful for final projects about AI or machine learning security risks.

- OWASP, **OWASP Developer Guide: Top 10**  
  https://devguide.owasp.org/en/02-foundations/05-top-ten/  
  Useful for final projects about web security, access control, cryptographic failures, injection, authentication failures, insecure design, and logging/monitoring failures.
