# Week 6: HTTPS, TLS, and Privacy Boundaries

## Week focus
This week clarifies what web encryption does well and what it does not solve by itself.
Core thread for the week:
- explain what HTTPS/TLS protects in transit
- interpret certificate trust basics (issuer, expiration, domain coverage)
- analyze third-party boundaries on secure pages
- connect technical security claims to privacy and ethical data-use decisions

## Recommended class flow
1. Concept framing (10-15 min): TLS, certificates, and trust claims
2. Live walkthrough (10-15 min): browser certificate inspection
3. Guided analysis (20-25 min): third-party requests and cookies in DevTools
4. Individual lab execution (25-35 min): evidence + short written analysis
5. Debrief (10 min): HTTPS security value vs unresolved privacy risk

## Week 6 files
- `week_06/TLS.pptx`
  Lecture deck for HTTPS/TLS trust, certificate interpretation, and privacy boundaries.
- `week_06/lab.md`
  Individual, no-hacking lab with screenshots and short responses focused on HTTPS limits, third parties, cookies, and a mini memo.

## Instructor note
This week is strongest when students separate:
1. transport security claims (encrypted connection), and
2. privacy governance claims (collection, retention, secondary use).
